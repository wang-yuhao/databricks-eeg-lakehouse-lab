## Core Concepts

### 1. Sleep Event Detection

Sleep spindles are brief (0.5–3 s) bursts of oscillatory activity at 12–15 Hz, generated by thalamo-cortical circuits. Detection involves:

1. Band-pass filter to 12–15 Hz (sigma band)
2. Compute RMS envelope
3. Find epochs where RMS > 1.5 × median for ≥0.5 s and ≤3 s

```python
from pyspark.sql.types import ArrayType, StructType, StructField, DoubleType, StringType

EVENT_SCHEMA = ArrayType(StructType([
    StructField("start_sec",  DoubleType(), nullable=False),
    StructField("end_sec",    DoubleType(), nullable=False),
    StructField("duration_s", DoubleType(), nullable=False),
    StructField("peak_amp_uv",DoubleType(), nullable=True),
    StructField("channel",    StringType(), nullable=False),
    StructField("event_type", StringType(), nullable=False),  # spindle / SO / k-complex
]))

@pandas_udf(EVENT_SCHEMA)
def detect_spindles_udf(signal: pd.Series, epoch_start: pd.Series) -> pd.Series:
    """Detect sleep spindles in each EEG epoch. Returns array of spindle structs."""
    def _detect(sig_list, start_sec):
        if sig_list is None:
            return []
        arr = np.array(sig_list)
        # Mock: return one synthetic spindle if signal is long enough
        if len(arr) >= 100:
            return [{
                "start_sec": float(start_sec + 5.0),
                "end_sec": float(start_sec + 6.5),
                "duration_s": 1.5,
                "peak_amp_uv": float(np.max(np.abs(arr)) * 10),
                "channel": "Pz-Oz",
                "event_type": "spindle",
            }]
        return []
    return pd.Series([_detect(s, t) for s, t in zip(signal, epoch_start)])
```

### 2. Working with Nested/Array Columns

```python
# Add spindle detection column (array of structs)
epochs_df = epochs_df.withColumn(
    "spindle_events",
    detect_spindles_udf(col("filtered_signal"), col("epoch_start_sec"))
)

# Explode to one row per spindle
spindles_df = (
    epochs_df
    .withColumn("spindle", explode(col("spindle_events")))
    .select(
        "subject_id", "study_night", "epoch_index", "sleep_stage",
        col("spindle.start_sec").alias("start_sec"),
        col("spindle.end_sec").alias("end_sec"),
        col("spindle.duration_s").alias("duration_s"),
        col("spindle.peak_amp_uv").alias("peak_amp_uv"),
        col("spindle.channel").alias("channel"),
    )
)

# Aggregate back to subject level
spindle_density = (
    spindles_df
    .groupBy("subject_id", "study_night")
    .agg(
        count("*").alias("total_spindles"),
        avg("duration_s").alias("mean_duration_s"),
        avg("peak_amp_uv").alias("mean_peak_amplitude_uv"),
    )
)
```

### 3. Array Functions Reference

```python
from pyspark.sql.functions import (
    explode,          # array/map -> one row per element
    explode_outer,    # like explode but keeps rows with null/empty arrays
    posexplode,       # like explode but also returns position index
    flatten,          # ArrayType(ArrayType(T)) -> ArrayType(T)
    array_distinct,   # remove duplicates from array
    array_sort,       # sort array elements
    array_contains,   # boolean: does array contain value?
    size,             # length of array
    slice,            # sub-array by start index and length
    transform,        # lambda-based element-wise transform
    filter,           # lambda-based element-wise filter
    aggregate,        # fold/reduce array to single value
    zip_with,         # combine two arrays element-wise
)

# transform example
df.withColumn(
    "spindle_starts",
    transform(
        col("spindle_events"),
        lambda s: s.start_sec
    )
)

# aggregate example: sum all peak amplitudes
df.withColumn(
    "total_amplitude",
    aggregate(
        col("spindle_events"),
        lit(0.0),
        lambda acc, s: acc + s.peak_amp_uv
    )
)
```

### 4. explode vs explode_outer

```python
# Data:
# subject_id | spindle_events
# SC4001     | [{start:5, end:6.5}]
# SC4002     | []   (no spindles this epoch)

# explode: drops empty/null arrays
df.withColumn("s", explode("spindle_events"))
# Result: SC4001 only

# explode_outer: keeps rows with null
df.withColumn("s", explode_outer("spindle_events"))
# Result: SC4001 with event, SC4002 with null
```

### Frequently Tested Array Patterns

```sql
-- Size of array
SELECT size(spindle_events) AS n_spindles FROM silver_epochs;

-- Filter array elements
SELECT filter(spindle_events, s -> s.duration_s > 1.0) AS long_spindles
FROM silver_epochs;

-- Transform array elements
SELECT transform(spindle_events, s -> s.peak_amp_uv) AS peak_amps
FROM silver_epochs;
```

## Research Context

**Sleep event types detected in this pipeline:**

| Event | Frequency | Duration | Significance |
|-------|-----------|----------|--------------|
| Sleep spindle | 12–15 Hz (sigma) | 0.5–3 s | Memory consolidation marker; drives hippocampal replay |
| Slow oscillation (SO) | 0.5–1 Hz | 1–3 s | Neocortical down-up state; synchronises with spindles |
| K-complex | Broadband | ~1 s | NREM arousal response; often co-occurring with spindles |

**Why event detection belongs in Silver:**
- Events are derived from clean, artefact-rejected signals (Silver output)
- Events are nested structs — richer representation than scalar columns
- Gold will flatten and aggregate events into summary statistics for ML

**Research relevance:** The SO-spindle coupling rate (events where a spindle occurs within 1 s of an SO up-state) is the primary predictor of memory consolidation quality (Helfrich et al., 2018 *Nature Communications*).
